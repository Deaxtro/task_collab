# Mini Task Collaboration App

## Overview
A simple task management system for users and admins.

## Features
- User registration & login (PHP & MySQL)
- Admin can view/delete all tasks
- Users can create/edit/delete their own tasks
- AJAX (Fetch API) for task operations
- Responsive design

## Setup
1. Import `database.sql` into MySQL.
2. Update DB credentials in `config/db.php`.
3. Run the app on a local server (e.g., XAMPP).

## Folder Structure
- `config/` – DB connection
- `includes/` – Auth and shared components
- `public/` – Main pages
- `api/` – Backend logic
- `assets/` – Styles
